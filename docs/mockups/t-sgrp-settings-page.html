Static mockup for t-sgrp — the agreed visual reference for the settings page, wired to nothing and shipped in no .vsix (.vscodeignore is an allowlist). It hard-codes the non-model settings for illustration; the real page derives them from package.json > contributes.configuration instead. Every control there writes ConfigurationTarget.Global, and the model grid is the one hand-built block.

Where the shipped page (media/settings.{html,css,js}) departs from this, deliberately: it has no light/dark switch — a webview inherits the editor's theme, and every colour there is a var(--vscode-*), which is what makes both themes work; labels and descriptions are derived from the manifest, so they read Context limit — percent rather than a hand-written phrase, and the descriptions are the real markdownDescriptions rendered through the board's markdown renderer (media/markdown.js); the per-slot colour swatches are dropped, since no per-slot colour exists anywhere else in the extension; and the grid carries no modified dot (the dot and Reset belong to the generic rows, exactly as drawn here).
